# n_TOF Gold Activation & Multiple Scattering Analysis Framework

A automated computational framework for neutron activation analysis and 3D Numba-accelerated Monte Carlo multiple scattering ($F_{\mathrm{ms}}$) corrections at CERN's n_TOF facility.

This software pipeline calculates Spectral Averaged Cross Sections (SACS) and expected $\gamma$-ray counts for irradiated target foils ($^{197}\text{Au}$), accounting for neutron spectrum attenuation, sample self-shielding, and 3D multiple scattering.

## ⚙️ Core Components

### 1. `runit.sh` (Master Workflow Automation)
The primary bash orchestration entry point. It manages input resolution, detects target geometries, automates Numba Monte Carlo simulations, and drives final activation table generation.

* **Key Responsibilities:**
  * Reads sample rows from target input tables inside `inputs/`.
  * Extracts distinct foil geometries (diameter, mass, and reaction channels $(n,\gamma), (n,2n), (n,4n)$).
  * Auto-generates runtime configuration decks (`params.txt`) and invokes `calculate_ms3.py`.
  * Caches calculated $F_{\mathrm{ms}}$ tables in `tempfiles/` to avoid redundant Monte Carlo runs.
  * Calls `calculate_counts3.py` to fold cross-sections and output final calculated vs. experimental count comparisons in `newtable`.

### 2. `scripts/calculate_sacs3.py` (SACS & Spectrum Integration Engine)
Performs fine-grid energy integration of nuclear cross sections folded with area-specific neutron flux distributions.

* **Key Responsibilities:**
  * Loads pointwise neutron cross sections ($(n,\gamma)$, $(n,2n)$, $(n,4n)$) and neutron spectrum files from `data/`.
  * Applies filter attenuation factors and foil self-shielding factor ($f_{\mathrm{ssf}}$) based on target thickness in atoms/barn.
  * Incorporates energy-dependent, 3D Monte Carlo multiple-scattering correction functions ($F_{\mathrm{ms}}(E)$) generated by `calculate_ms3.py`.
  * Integrates effective cross sections to yield Unattenuated, Filtered, Self-Shielded, and Multiple-Scattering corrected SACS values (in barns).

### 3. `scripts/calculate_ms3.py` (3D Numba Monte Carlo Simulator)
A 3D Numba-accelerated Monte Carlo simulation engine modeling neutron transport within cylindrical foil targets.

* **Key Responsibilities:**
  * Simulates individual neutron trajectories taking into account elastic scattering, capture, and threshold reaction channels ($(n,2n)$, $(n,4n)$).
  * Evaluates the enhancement of reaction probability due to path-length elongation and secondary scatterings inside the target geometry.
  * Computes energy-binned pointwise correction factors:
    $$F_{\mathrm{ms}}(E) = \frac{\sigma_{\mathrm{eff}}(E)}{\sigma_0(E)}$$
  * Emits correction datasets into `tempfiles/fms_d<DIAM>_m<MASS>_<REACT>.dat` for integration into SACS calculations.

## 🚀 Quick Start & Usage

### Execution Syntax

```bash
./runit.sh <input_file> [flux_variant] [bpd] [--no-ms]
```

### Options & Arguments
* `<input_file>`: Name of input file inside `inputs/` (e.g., `input_NEAR_BurialDating`).
* `[flux_variant]`: Flux variant tag for NEAR station in `data/` (default: `MCecc`).
* `[bpd]`: Energy bins per decade for logarithmic numerical integration (default: `200`).
* `--no-ms`: Flag to bypass Monte Carlo simulation pass and assume $F_{\mathrm{ms}} = 1.0$.

### Usage Examples

1. **Full 3D Monte Carlo + Activation Workflow:**
   ```bash
   ./runit.sh input_NEAR_BurialDating MCecc 200
   ```

2. **Fast Run (Skip Monte Carlo Multiple Scattering):**
   ```bash
   ./runit.sh input_NEAR_BurialDating MCecc 200 --no-ms
   ```

3. **Explicit Subfolder Input Reference:**
   ```bash
   ./runit.sh inputs/input_NEAR_BurialDating MCecc 200
   ```

## 📊 Output

Upon successful execution, the aggregated results table is saved in the root directory as **`newtable`**. It contains:
* Derived geometric sample details (thickness in mm, areal density).
* Unattenuated (`SACS`), Filtered (`f-SACS`), Self-shielded (`ssf-SACS`), and Multiple Scattering Corrected (`ms-SACS`) cross section values.
* Total integrated neutron fluence density ($\phi_{\mathrm{tot}}$).
* Calculated $\gamma$-counts ($C_{\mathrm{calc}}$), experimental counts ($C_{\mathrm{exp}}$), and calculated-to-experimental ratio ($C/E$).
